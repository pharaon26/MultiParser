# MultiParser

CLI-инструмент для парсинга товаров и вакансий с Wildberries, Лабиринт и hh.ru.
Результат сохраняется в Excel-файл с автоматическим форматированием.
Отчет также включает в себя картинки (фотки товаров, обложки книг) в формате либо изображения, либо веб ссылки на изображение 

## Установка

```bash
pip install -r requirements.txt
```

Для Wildberries нужен установленный Google Chrome. Драйвер `webdriver-manager` скачает подходящий chromedriver сам.

## Использование

```bash
python cli.py <источник> "<запрос>" [--pages N] [--output файл.xlsx]
```

Варианты источника: `wb`, `labirint`, `hh`.

Примеры:

```bash
python cli.py wb "iphone" --pages 2
python cli.py labirint "python" --pages 3 --output books.xlsx
python cli.py hh "python developer" --pages 2
```

## Структура проекта

```
cli.py                  - точка входа, разбор аргументов, выбор источника
parsers/base.py         - общие функции: запрос страницы, сохранение в Excel
parsers/wildberries.py  - парсинг Wildberries через Selenium (сайт рендерится JS)
parsers/labirint.py     - парсинг Лабиринта + скачивание обложек
parsers/hh.py           - парсинг вакансий hh.ru
```

## Ограничения

- Верстка каждого сайта меняется без предупреждения - если парсер перестал находить данные,
  вероятно, изменились CSS-классы или `data-qa` атрибуты, и нужно поправить селекторы в
  соответствующем файле `parsers/<источник>.py`.
- Проект сделан в учебных целях. Перед регулярным/массовым использованием ознакомьтесь
  с `robots.txt` и пользовательским соглашением соответствующего сайта.
